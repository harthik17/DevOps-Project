Technical Specifications & Stack

  • Backend Framework: FastAPI 0.115+, Uvicorn ASGI server
  • Observability: Prometheus 3.0+, Grafana latest, custom Alert rules
  • AI & Machine Learning: Scikit-Learn Random Forest Pipeline, Joblib serialization
  • Model Explainability: SHAP (SHapley Additive exPlanations) TreeExplainer
  • Containerization: Docker, Docker Compose multi-service network
  • Orchestration: Kubernetes (Minikube compatible) with dry-run previews
  • Public Delivery: Cloudflare Tunnel (HTTP/2 edge proxy with TLS)

Engineering Truths & Safety Boundaries

Synthetic Data Transparency: Model evaluation metrics (ROC-AUC 0.751) reflect synthetic telemetry designed for pipeline demonstration. They must not be cited as real-world production accuracy.
Heuristic vs. Causal Reasoning: The Root Cause Analysis (RCA) engine implements transparent symptom scoring; it provides triage guidance rather than physical causal proof.
Production Safety: Kubernetes automated scaling and rolling restarts are locked in dry-run mode by default (`executed: false`). Production execution requires strict opt-in authorization and RBAC auditing.
